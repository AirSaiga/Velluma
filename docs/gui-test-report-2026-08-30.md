# Velluma 前端全功能 GUI 测试报告（三轮，2026-08-29/30）

> 测试形态：纯 Web（FastAPI 8005 托管 dist，同源 /api，浏览器黑盒 GUI 测试）。
> 载体：新建《GUI测试书-可删除》《GUI测试书2-交互覆盖》《GUI测试书3-世界链路》三本测试书执行全部写操作，真实书只读；测试后全部删除，DB 零残留。
> 证据：`gui-test-screenshots/`（42 张，t*/r2_* 前缀对应轮次）。

## 结论

约 40 个测试点，通过率 100%（除环境限制项）。**发现 3 个高置信应用缺陷（未修，待拍板）+ 若干轻观察**。第三轮定性「输入冻结」为测试宿主（IAB guest）问题，非应用缺陷。

## 缺陷清单（按修复优先级）

### D1 打算页就地编辑不落库（丢稿风险最高）
- 现象：副驾「打算」tab 的一句话意图/非写不可情节，编辑后永不落库（两章 spine 均 null；失焦触发无效；等待 >10s 无效）。
- 定位：`frontend/src/features/workspace/composables/useChapterSpine.ts` 的 `@change → setIntent → watcher 2s 防抖 save()` 链路失效；后端 `PATCH /chapters/{id}/adaptive/spine` 直连正常；走直接 `save()` 的「收下」正常。保存失败按设计静默（`useChapterSpine.ts:100-103` 吞错），用户无从察觉。
- 连带：失焦前发生重渲染会把未提交输入直接清空（值只存在于 DOM，v-model 未感知）。
- 复现：新建章 → 打算 tab 输入一句话 → 失焦/等待 → `GET /api/chapters/{id}/adaptive/spine` → `{"spine":null}`。
- 修复建议：审查 watcher 链路与静默吞错取舍；顺手考虑 input 防抖替代 @change。

### D2 快速创建弹窗阻塞路由换装
- 现象：创建书籍成功自动跳转时，URL 已切新书工作台但视图卡死在书架+弹窗（>25s 不自愈）；手动关闭弹窗后视图立即完成换装。
- 复现：书架 → 快速创建 → 填名 → 创建 → 观察。第一轮的「首切白屏 ~10s 自愈」为同机制轻度表现（无弹窗在场时）。
- 修复建议：创建成功路径先关弹窗再跳转，或排查 Transition 完成条件被弹窗挂起的原因。

### D3 新建书籍向导无退出入口
- 现象：向导两步全按钮清单核查只有「← 上一步」，无取消/关闭；退出只能刷新页面或走完向导。
- 修复建议：头部加 × 或取消钮。

## 轻观察项

- 发布成功后 binder 徽标仍显「已生成」，未即时刷新（后端 status=published 已验证）。
- 工作台/世界页首次进入白屏数秒（899KB/567KB 懒加载 chunk）。
- API Key 缺失时发布仅一条 warning toast 提示降级，摘要/角色状态静默跳过（后端先置 published 再跑 LLM 的降级设计本身验证无误）。
- 「已新建章节」toast 疑似长时间残留不自动消退。
- Esc 弃置理由 chips（幽灵 ≥30 字蒸发）三轮均未能截图取证，待人工确认。

## 判定为非应用问题

- 输入冻结现象（真实输入通道+截图管线多次同步冻结）：第三轮实证应用对合成事件全部正常响应，定性为测试宿主（IAB guest）问题，Electron 真机不受影响。已从缺陷清单降级。

## 全覆盖清单（通过项）

书架（加载/快速创建/校验/编辑书卡/导入入口/向导/删除）；写作台（章节增删流/打字自动保存/幽灵续写+Esc蒸发/选中浮窗 B/I/U/章节动作菜单/智能格式整理/快捷键弹窗/AI 辅助开关/AI 视角+五模式预览/副驾四 tab/谋篇建议+收下/此刻切片+改时间/叙事锚落库）；发布链（draft→published+确认弹窗+降级路径）；世界页（地图/实体点/详情抽屉/真相/伏笔/地点抽屉/记一笔→入账/实体创建/真相句子录入/埋伏笔/罗盘/panel=canon 深链）；文风（零状态坡道/合成输入测量 9 句指纹/发布后章节收编 sample_count 1）；数据页三 tab；设置弹窗掩码；协作埋点（collab_events.jsonl 128 条含 spine_suggest/adopt）；toast 与确认弹窗体系。

## 环境限制（自动化不可达，留人工回归）

幽灵 Enter 采纳（需真实按键送达 TipTap）；文件实选导入（IAB 不支持原生文件选择器）；响应式窄窗布局；Ctrl+1~4 快捷键（宿主键盘通道冻结期无法测）。
