# 写作台「AI 视角」侧栏 · 说明报告

> 现状基线：2026-09-15 轻量化重构后（简报卡 + 空块静音 + 底层手风琴 + 光标真切片，全部已施工）。
> 定位一句话：**让作者两秒钟看懂「AI 懂不懂现在的现场」，想逐字核对时随时能下潜到 AI 读到的每一个字**——上层是提炼，下层是原文，两层出自同一次装配。
> 相关文档：设计稿 `docs/design/ux-redesign/09-ai-view-redesign.md`（含 2026-09-15 批注 #4）、可行性报告 `docs/ai-view-briefing-feasibility.md`、前次调研 `docs/ai-view-panel-report.md`。

## 1. 怎么打开

| 入口 | 操作 |
|---|---|
| 右缘助手栏 | 第 6 格「🔍 AI 视角」图标（AI 辅助总开关之后；点击开、再点收） |
| 快捷键 | **Ctrl+5** 直达（面板分区序：打算 1 / 此刻 2 / 本章 3 / 检查 4 / AI 视角 5） |
| 钉住 | **Ctrl+\** 三态：关→开并钉 / 开未钉→钉 / 已钉→收并解钉（钉住态跨会话恢复） |
| 关闭 | Esc（未钉时；焦点在输入框不收）· 面板外点击（未钉时）· 面板头 × |

面板是贴 44px 右缘栏左侧浮出的**单分区抽屉**（宽 `min(380px, 44vw)`），一次只显示一个分区，与其他四分区互斥切换。未选章节时显示「从左侧选择一个章节。」。

**数据获取节奏**：进分区且无数据 → 自动装配一次；之后靠 ↻ 手动刷新；模式切换 → 有数据才重拉；切章 → 旧数据立即清空不再示人，若仍停在本分区自动重拉一次。

```

│
│  AI 此刻读到的
│  AI 续写时将参考以下事实与约束；态势一眼可辨，逐字细节收在底层。
│
│  ② 汇总行：第2177年3月4日 · 来自本章固定 · 设定来自世界页      [↻]
│
│  ┌─ ③ 战局态势（简报卡，主角）────────────────┐
│  │ 场景     机房 [正文推导] [中插]              │
│  │ 在场     林尘（在途·进度40%）、明姐           │
│  │ 焦点物件 锈铁盒——周砚随身携带的铁盒           │
│  │ 守死秘密 周砚：知道女儿还活着…                │
│  │ 引力     送别之后回城，试探工头的口风  你的打算 │
│  └─────────────────────────────────────────────┘
│
│  ④ [顺写][拼画面][连写][细纲][写开头]   ← 模式五档（检索锚）
│
│  ⑤ ▸ 查看底层原始提示词细节（共 2,031 字）  [原文]  ← 默认折叠手风琴
│     └ 展开后：三段分组 × 14 块折叠卡（保字排版/预算条）
│
└─ ⑥ ▸ AI 眼中的世界（底部折叠卡：方向/事实/走向/已整理）
```

- **①健康横幅**：感知组件（方向猜测/走向推测/卡舱供件等 7 类）最近一次出错的台账，恢复了自动消失，不影响写作——信任问题最先看到，但平时不占一行。
- **③简报卡**与**⑤手风琴**是本次重构的双主角，下文分节展开。
- **⑥世界模型卡**：点开拉 `GET /adaptive/model`，四行结构化摘要（方向[来源人话化]/事实 N 条[只计活事实]/走向/已整理字数）。

## 3. 战局态势简报（上层 · 两秒扫完）

五行全部来自**同一次上下文装配的结构化副产品**（零 LLM、零 token、零新增查询）。**行空整行不渲染**——简报层不做「还没录」式催收；五行全空（如零设定空书）显示单行灰字「暂无态势」。

| 行 | 内容与读法 | 数据来源 | 什么时候缺席 |
|---|---|---|---|
| **场景** | 地点名 + 两个小标签：**正文推导**（绿，=AI 从光标前文的转场句推出现场，标签后的 via 如「走进·机房」）或**本章钉**（灰，=你在世界页钉定的场景地点）；**中插**（紫，=光标停在已写正文中间的骨架跳写态，简报按光标现场而非文末装配） | 光标派生取景框 `resolve_active_scene`（回退本章钉） | 无场景钉且正文无转场句 |
| **在场** | 存活人物名 + 此刻状态后缀（如「林尘（在途·进度40%）」，状态由世界事件推演）；正文高频出现的未建档人名会以「正文高频出现 · 未建档（临时在场）」出现在此——提示你去世界页建档 | dock 在场投影 `onstage_projection`：场景作用域内存活 ∪ 当前段落提及（名字/别名命中）；死者不进 | 未接世界页的书（legacy）恒无此行；世界页建了实体但不在场景作用域且正文未提及 |
| **焦点物件** | 当前段落提及的资产（提及即在场——世界折叠不携带资产位置） | 同上（资产通道） | 同上 |
| **守死秘密** | AI 知晓但绝不能直接写出的条目摘要（≤6 条 × 36 字）：整人私有实体的档案 + 档案里标「秘密」的字段（标「半露」的不算守死，不入行） | `character_secrets` + `field_layer_secrets(level=secret)` | 无私有实体、无字段级秘密 |
| **引力** | 当前写作方向 + 来源标签：**你的打算**（spine）/ **大纲** / **AI 猜的**（推断方向，亮身份不冒充作者材料）/ **上一章接力**（章首接力棒）/ **本次请求** | 装配意图链：请求/大纲节拍/层 2 推断 > `chapters.spine.intent` | 无 spine、无大纲节拍、AI 未推断出方向 |

**可信度口径**：简报是提炼视图，不是逐字注入——「AI 实际读到的每一个字」在下层手风琴里，两层出自同一次装配（同一 `StitchContext`），简报与注入不可能漂移。

## 4. 模式五档（检索锚切换）

| 档 | 后端 mode | 检索锚 | 什么时候看 |
|---|---|---|---|
| 顺写 | continue | 光标前文顺句 | 默认档，对应 Space 续写 |
| 拼画面 | stitch | 卡舱零件锚定 | 看微镜头缝合时读什么 |
| 连写 | burst | 检索面更大（样本 k=3） | 走向卡连写 |
| 细纲 | outline | 胶囊前后文双端锚定 | 细纲胶囊扩写 |
| 写开头 | open | 大纲整章检索 | 新章开篇 |

不同模式的**召回记忆/文风样本/称呼表取材**不同（下层块随之变化）；简报的场景/在场/秘密行与模式无关，引力行在大纲兜底时会随档位变化。模式切换时旧数据半透明冻结 + 扫描条（布局零跳动），展开态与折叠态原样保留。

## 5. 底层逃生舱（下层 · 逐字核对）

默认折叠，头行 `▸ 查看底层原始提示词细节（共 N 字）`；右侧「**原文**」开关点击时顺带展开。展开后完整继承 09 期重设计资产：

- **三段分组 = 注入序可感知**：事实与设定（场景身份→本章打算→在场与相关→实体称呼→Canon→私有设定→世界观→关系）→ 约束与记忆（禁词→回响→空间）→ 文风与笔感（画像→样本→白描封杀令）。段是视觉切分，块才是折叠单元。
- **块折叠头行即仪表盘**：箭头/标题/`N 字 · 来源`（来源人话化：世界页·实体档案/真相账本/文风样本库…）+ 2px 预算占用条（超支变红 + 「预算超支，8 条 → 3 条」被裁说明）。默认只展开「场景身份」（首位且短）。
- **展开即全量**：无内部滚动，长档案完整流式显示，滚动交给面板单一滚动条。
- **保字排版**：块正文按 prompt 字面格式解析成排版结构（# 标题/列表/档案体衬线+左竖线/【在场】绿 chip/【已死亡】红 chip/【此刻·切记】钉行），**字不增不删不改写**（对拍测试 `contextBlockFormat.test.ts` 锁定）；「原文」开关一键回退等宽逐字直出——解析不完美时的总兜底。
- **空块静音**：本次没注入的块不渲染、不留虚线催收框（「未配置」的补录地图见 §7）。

## 6. 光标真切片（FIM 中插不撒谎）

面板请求随行携带**光标窗口**（编辑器在场时）：光标前 500 字 + 光标后 150 字。

- **普通写作**（光标在文末/段尾）：光标前文作装配输入，与真实 Space 续写读到的现场一致。
- **骨架跳写中插**（光标停在已写正文中间）：简报与块按**光标现场**装配——场景行派生自光标前的最近转场句、带「中插」标记，而不是错误地读到章节末尾的语境。光标后 150 字只用于标记中插态，**不进装配**（AI 续写时也读不到你的后文，面板如实呈现这一点）。
- **切页/未进章**（编辑器不在场）：回退读落库章节尾部（旧路径）。

⚠ 面板数据是**请求时刻的快照**：移动光标或改正文后，点 ↻ 刷新才会按新现场重新装配。

## 7. 空行补录地图（静音之后的「去哪录」）

空块催收框已退役，此表是它的文档形态替代——想让简报多出一行/块里多一块，去这里录：

| 想要的行/块 | 去哪录 |
|---|---|
| 场景行出现 | 世界页给本章钉场景地点，或正文里自然写出转场句（「他走进机房。」） |
| 在场行出现 | 世界页建角色 + 记事件（移动/到场类），或正文直接提及角色名 |
| 焦点物件行出现 | 世界页建资产，正文提及它 |
| 守死秘密行出现 | 世界页实体设为「私有」，或档案字段旁 chip 标「秘密」；真相账本记条目 |
| 引力行出现 | 助手面板「打算」写一句 spine 意图（快速创建新书时的一句话打算也落这里），或大纲写节拍 |
| 文风画像/笔迹示范块 | 文风页填画像、收亲笔样本（「收本章为文风范例」一键装填） |
| 前情回响块 | 多写多发布——记忆按章自动索引，越写越厚 |

## 8. 交互状态记忆（纪律）

| 状态 | 模式切换/刷新 | 切章 |
|---|---|---|
| 手风琴开合 | 保留（保持整洁折叠态） | 复位为折叠 |

所有折叠/开关态均为组件内状态，**不持久化、不入 localStorage**（启动脚本换 origin 漂移的既往教训）。

## 9. 边界与已知未做

- **`unselected`（知识平面未选清单）已随响应下发但前端未消费**——「哪些设定没被选中、为什么」的审计闭环只建成了一半，是否并入简报层待拍板。
- 简报「在场」行沿用了 dock 在场投影的口径（含临时通行证未建档人名）；`offstage_characters` 等台下信息未进简报（避免信息过载）。
- legacy 书（未接世界页）简报只有场景/引力两行可能在场——属预期降级，不是故障。
- 面板装配与 stitch-ghost **同源共用** `assemble_stitch_context`（同源红线：禁止平行实现），但预览不生成文本、不消耗 token；真实续写的最终 prompt 还包含 user 侧动态段（碎片/目的地框等），预览呈现的是 system 侧知识注入的全量。
