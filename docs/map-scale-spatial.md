# 比例尺标定与空间简报设计（D4）

> 状态：设计稿（D4 拍板产物，2026-08-18）。拍板结论：投入，设计委托 Agent 完成。
> 解封 `docs/world-writing-bridge.md` W5 缓行项①（比例尺校准与距离/旅程常识 →
> spatial_brief）。原缓行理由：「无标定时无法诚实给数」——本设计给出标定方案。
> 范围：`models.py`（books.map_scale）+ 世界页标定交互（胶囊条/罗盘区）+
> 前端 engine 与后端 `services/world/` 的同构距离换算 + settings_bundle 空间块。
> 前置：活舆图 M6+（Leaflet CRS.Simple 单画布、空白舆图、罗盘已落地）；
> W5 lite（场景钉/读者视角滤镜/相遇提示）在役。

---

## 0. 背景、目标与非目标

**背景**：世界页地图运行在 Leaflet `CRS.Simple` 自定义坐标系上——`world_map_layers`
的 x/y/w/h、地点/实体/笔迹的全部坐标都是「内部单位」，图上一厘米不对应任何现实
距离。后果：系统无法诚实回答「A 到 B 多远、要走几天」，相遇提示只能说「同地」
不能说「相距半日脚程」，走向卡的地理建议永远是模糊正确，正文里 AI 若写行程数字
就是在编。

**目标**

1. 作者用**一次拉线动作**给地图标定尺度（玩具感：像给地图配图例）；
2. 系统获得诚实的距离/旅程换算能力（纯函数，前后端同构）；
3. 空间常识分层喂到：切片条/情境浮卡（作者看）→ 生成上下文（AI 用）。

**非目标**

- 不做地形/路径规划/导航（直线距离 × 绕行系数的**估算**，永远带「约」）；
- 不做实时行程追踪；不改事件溯源模型（距离是派生量，不是事实源）；
- 不强制任何现实单位制（架空世界友好，见 §2.2）；
- 多底图拼贴书的逐图层标定不做（尺度挂书级，前提声明见 §2.1）。

---

## 1. 设计原则

| # | 原则 | 落实 |
|---|------|------|
| S1 | **标定 ≤ 3 步** | 拉线 → 选档 → 完成。标不定不影响任何现有功能（静默降级，同 context-card 哲学）。 |
| S2 | **作者的语言** | 内部基准是「步行日」，展示层永远说作者的话（「约 2 天步程」「约三百里」），不出现公里除非作者自己选。 |
| S3 | **诚实给数** | 所有输出带「约/粗估」；换算链路的每个系数可见可调；标定错了随时重标，全部数字即时重算（纯函数无快照，天然支持）。 |
| S4 | **玩具感** | 标定完成后地图左下出现比例尺角标（像真地图的图例），随缩放重算长度——它本身就该好玩。 |

## 2. 数据模型

### 2.1 `books.map_scale`（新增 JSONB 列，MIGRATIONS 加列）

```jsonc
{
  "refs": [                       // 标定参考线（可多条，取均值；最多保留 5 条）
    { "ax": 120.5, "ay": 64.0, "bx": 210.2, "by": 64.0,   // CRS.Simple 内部坐标
      "days_foot": 1.0, "label": "骑马一天" }               // 该线段代表的现实长度
  ],
  "unit_name": "里",              // 可选：作者惯用单位名（里/公里/格/自造词），空=只说「步行 N 天」
  "unit_per_day_foot": 60.0,      // 可选：1 步行日 = N 个作者单位（缺省不换算，仅展示步行日）
  "detour_factor": 1.2,           // 绕行系数（估算直线×此系数），可调
  "modes": { "walk": 1.0, "horse": 2.5, "boat": 2.0, "caravan": 0.7 }  // 相对步行日的速率，可调
}
```

**为什么挂 books 不挂 world_map_layers**：CRS.Simple 坐标空间是**书级共享**的——
底图层、地点、实体、手绘笔迹、事件落点全部活在同一个坐标系里，尺度是坐标空间的
属性而非某个图片层的属性；且空白舆图（无底图层）也必须可标定。多底图拼贴且各图
尺度不一的书属于前提外场景，文档声明不支持（S1 的代价）。

### 2.2 空白舆图特例

空白舆图（`blankAtlas.ts`，Natural Earth 50m，等距圆柱投影，viewBox 2:1）**自带
隐含地球尺度**——图宽即赤道周长。检测到当前书使用空白舆图时，`map_scale` 预填
建议值：图宽 ≈ 40,000 km ≈ **步行 1,300 天**（内部按 1 步行日 ≈ 30 km 换算，
该常数进换算层配置），作者可改可推翻。架空世界书自己拉线（S1）。

### 2.3 内部基准：步行日

一切距离先换算为「步行日」（浮点），展示层再按 `unit_per_day_foot` 或交通方式
换算。理由：步行日是前工业叙事里最普适的尺度直觉（「三日路程」），且与后续
spatial_brief 的行程常识天然同单位。

## 3. 标定交互（世界页）

1. 胶囊条「⋯」菜单加「⚖ 标定比例尺」→ 进入标定模式（画布提示「拉一段你有感觉
   的距离」，复用手绘笔迹的落点手势，Esc 退出）；
2. 作者拉线松手 → 线段旁浮小卡：「这段路相当于？」快捷档：**步行一天 / 骑马一天 /
   乘船一天 / 自定义**（数字 + 单位名，自定义可顺手填 `unit_name` 与
   `unit_per_day_foot`）；
3. 确认即完成——比例尺角标出现在地图左下（罗盘同族视觉），标定参考线默认隐藏
   （角标悬停可显示/管理/删除重标）。

- 多条参考线取均值（防一次手滑定终身）；≤5 条，先进先出；
- 已有实体/地点的书标定后**即时生效**（§4 纯函数重算，无迁移）。

## 4. 换算层（纯函数，前后端同构）

- 前端：`features/world/engine/distance.ts`（与 `computeWorldState.ts` 同目录同风格，
  配单测）；
- 后端：`services/world/spatial.py`（供 settings_bundle / scene-slice 消费）；
- 函数签名（两侧对齐）：`crs_distance(a, b) → days_foot(map_scale) →
  format_distance(days, map_scale, mode?) → "约 2 天步程" / "约三百里（骑馬半天）"`；
- 换算链：`CRS 直线距离 → px_per_day（refs 均值）→ 步行日 → ×detour_factor →
  按 mode 速率折算 / 按 unit 换算`；
- **等距圆柱的纬度失真**（空白舆图高纬度横向拉伸）：第一版不修（「度」——架空书
  未必当地球用）；留 `lat_correct: false` 开关位，二期视真实使用再议。

## 5. 消费场景（分期兑现）

### D4-2 作者可见层

- **切片条「此刻」**：在场角色相互距离行（「甲 · 距乙约 2 天步程」）；脚下块加
  「最近锚点地点：北岸要塞 · 约半日」；
- **情境浮卡**：地点卡加「距本章场景钉约 N 天步程」；
- **相遇提示升级**（W5 lite 已有）：从「同地同时在场」升级为分档——同地 / 相距
  半日内可达 / 相距 1-3 天（文案「甲与乙相距一日脚程，赶路可及」）；
- **时间轴/弧线带不动**（空间与编年史正交，别贪）。

### D4-3 生成上下文层（spatial_brief 本件）

- `settings_bundle` 世界优先链路的世界切片加**空间块**（仅 world_sourced 且有
  map_scale 时注入，双门槛静默降级）：
  ```
  【空间常识·粗估】在场：甲/乙（同处北岸要塞）；丙在王城，距此地约 6 天步程
  （骑马约 2 天半）。本章场景钉：北岸要塞。
  ```
- 预算护栏：只列在场实体 + 本章场景钉相关距离，≤3 行；同地省略距离；
- 走向卡/未来推测组件经 settings_bundle 自然吃到（不单独接线）；
- finish 审计**暂不**加行程一致性检查（值得做但等 D4-3 数据：先看 AI 用不用
  这些数字，再决定要不要拿它当尺子审）。

## 7. 风险与开放问题

- **标定错误**：随时重标、即时重算（S3），无持久派生数据可腐坏——这是本设计
  刻意保持纯函数的原因。
- **架空尺度感**：作者随手一标导致数字离谱（全城相距 0.01 天）——自定义档给
  参考文案（「步行一天 ≈ 平原 30 公里 ≈ 县城到邻县」），不强制。
- **纬度失真**：等距圆柱横向距离随纬度膨胀，空白舆图两缘失真明显——一期接受，
  `lat_correct` 开关位预留，视使用数据再议。
- **多尺度拼贴书**：声明不支持（一个书一个尺度）；真出现诉求再评估挂层级的
  迁移成本。
