# 世界页 × 写作页桥接功能 · QA 测试指南

> 适用版本：写作桥 W1-W5lite（切片条 / 情境浮卡 / 速记入账 / 候选回流 / 深链往返）
> 读者：QA 测试人员。本文只描述界面行为与操作步骤，不涉及实现细节。
> 结果判定：每条步骤均给出「预期结果」；不符即记缺陷（见 §9 记录建议）。

---

## 0. 测试准备

### 0.1 环境要求

- 前后端服务已启动，可正常进入应用；
- **AI 模型已配置且可用**（速记解析、沉淀/完稿的候选抽取依赖模型；模型不可用时相关用例按 §8 的降级预期执行）；
- 建议使用两份窗口/屏幕：一个开写作页、一个开世界页（§6 双开同步测试需要）。

### 0.2 测试数据准备

| 编号 | 数据要求 | 用途 |
|------|----------|------|
| 书 A（已启用世界页） | 世界页有 3 个以上角色、2 个以上地点、若干事件；其中包含：一个已死亡角色、一个处于移动途中（移动事件设了持续天数）的角色、两个位于同一地点的角色、至少一条开放伏笔 | 大部分用例 |
| 书 A 补充 | 至少一个角色的可见性为「作者已知（private）」；至少一章已设置章节叙事时间锚（世界页时间轴右键 →「标记本章叙事时间」）；存在至少一个有疆域的势力，疆域覆盖某个有坐标的地点 | 读者视角、脚下控制区 |
| 书 B（未启用世界页） | 世界页从未建过实体 | 迁移引导空态 |
| 书 C（可选） | 有实体但**没有任何事件** | 切片空态 |

### 0.3 通用入口

- **切片条**：进入某书任意章节的写作页 → 打开右侧副驾面板（鼠标悬停窗口右缘，或按 `Ctrl+\` 固定）→ 切到「**设定**」tab。面板标题为「**此刻此地**」。
- **世界页**：左侧导航「世界」进入；书内跳转也可从切片条/浮卡的按钮进入。

## 1. 切片条（此刻此地）

前置：书 A，选中一个**已设置叙事时间锚**的章节，打开「设定」tab。

| # | 操作步骤 | 预期结果 |
|---|----------|----------|
| 1.1 | 查看切片条头部 | 显示「此刻此地」+ 一个日期（如「第5年3月12日」）+ 来源徽标「本章锚」；日期与世界页时间轴上该章锚定时刻一致 |
| 1.2 | 切到一个**未锚定**、但前面章节有锚的章节 | 日期跟随前序最近锚，徽标变为「承前章」（鼠标悬停徽标有解释文字） |
| 1.3 | 查看在场列表 | 列出该时刻有事件记录的角色；存活者在前、已死亡者灰显并标注「已死亡」；在途角色显示「位于X · 在途（进度 N%）」样式文字 |
| 1.4 | 点击某个在场角色行 | 跳转世界页：游标停在本章时刻、该实体的详情抽屉打开，页头出现「返回本章」按钮 |
| 1.5 | 查看「脚下」块 | 显示场景地点名称；若该地点处于某势力疆域内，显示「XX 控制区」标签 |
| 1.6 | 点击「脚下」的「钉住」 | 按钮变为「📌 已钉 · 取消」；刷新页面后仍保持钉定状态 |
| 1.7 | 点击「取消」 | 回到自动推演的地点；再次刷新仍是自动推演 |
| 1.8 | 查看是否有「相遇」块 | 同一地点的两个角色以「名字A × 名字B · 地点名」呈现（书 A 数据满足时） |
| 1.9 | 查看「头顶的线」 | 伏笔行（含「悬空 N 章」）、期待行（含「张力 N」）各至多显示 2 条；超过时底部出现「更多线索在世界页 »」，点击跳世界页 |
| 1.10 | 点击头部「读者视角」按钮 | 按钮点亮；可见性为「作者已知」的角色从在场列表消失；伏笔块整体隐藏；期待块保留 |
| 1.11 | 再次点击关闭读者视角，离开页面再回来 | 过滤状态被记住（开着的回来还开着） |
| 1.12 | 点击头部整行 | 切片条主体折叠/展开；折叠状态在离开页面后仍被记住 |
| 1.13 | 切换到书 B 的任意章节 | 切片条显示迁移引导文案与「前往世界页」按钮，不显示空的数据块 |
| 1.14 | 切换到书 C（有实体无事件）的章节 | 在场块显示引导文案（提示录事件或锚定时间），其余块按数据缺席隐藏，无报错 |

### 本章时刻编辑（切片条「改」）

| # | 操作步骤 | 预期结果 |
|---|----------|----------|
| 1.15 | 点击时刻旁的「改」 | 展开编辑器：世界日数输入框 + 日期预览 + 「锚定 / 清除锚 / 取消」 |
| 1.16 | 修改日数，观察预览，点「锚定」 | 编辑器收起；头部日期变为新值，徽标变为「本章锚」；在场等各块随新时刻变化 |
| 1.17 | 再次「改」→「清除锚」 | 日期回落到前序章锚（或推演值），徽标离开「本章锚」 |
| 1.18 | 在编辑器中按取消 / Esc | 无任何变化 |

## 2. 情境浮卡

前置：书 A，进入章节并点击正文进入可编辑状态。

| # | 操作步骤 | 预期结果 |
|---|----------|----------|
| 2.1 | 用鼠标选中正文中的一个**角色全名**（约 2-4 字），停顿约 1 秒 | 选区下方浮出小卡片：类型徽标（角色/资产/地点）、名称、此刻状态（位于X/在途/已死亡）、一句话简介、编年史至多 3 条（每条含事件类型、备注、日期） |
| 2.3 | 选中一个**地点名** | 浮出地点卡：所属控制区（有疆域数据时）、此地最近 3 条事件 |
| 2.4 | 选中角色的**别名**（若配置过） | 同样能浮出该角色的卡 |
| 2.5 | 选中一段**长文本**（超过 12 字） | 不出现浮卡（长选区属于润色场景） |
| 2.6 | 选中一段**不是任何实体/地点**的文字（如「他慢慢走过去」） | 不出现浮卡，也无报错 |
| 2.7 | 在正文中**点击一个 @ 角色提及**（蓝色标记） | 浮出该角色卡（内容同 2.1） |
| 2.8 | 点击一个 # 资产提及 | 浮出资产卡 |
| 2.9 | 浮卡出现后，点击卡片以外的任意位置 | 卡片关闭 |
| 2.10 | 浮卡出现后，把光标点回正文别处 | 卡片关闭 |
| 2.11 | 浮卡出现期间查看选区上方的「润色」工具浮层 | 两个浮层同时存在且互不遮挡关键按钮，均可正常操作 |
| 2.12 | 点击浮卡「在世界页打开 →」 | 跳世界页：游标停在本章时刻、对象定位/抽屉打开、页头出现「返回本章」 |
| 2.13 | 点击浮卡「记一笔」 | 速记框打开，输入框已预填该实体名（见 §3） |
| 2.14 | 卡片内容与切片条/世界页一致 | 同一角色在切片条、浮卡、世界页抽屉三处显示的位置/生死一致 |

## 3. 速记框（一句话记历史）

前置：书 A，光标聚焦在正文编辑区。

| # | 操作步骤 | 预期结果 |
|---|----------|----------|
| 3.1 | 按 `Alt+N` | 弹出「记一笔 · 世界速记」小窗，含一行输入与「解析」按钮 |
| 3.2 | 输入一句明确事实（例：「第3年春，林尘率三百人攻下北岸要塞」）→ 点「解析」或回车 | 1-3 秒后变为预填表单：类型（如「战斗」）、参与者（角色名标签）、地点、时刻（带日期预览）、备注均已填好 |
| 3.3 | 修改表单：换类型、增删参与者（标签上 × 删除，「＋添加」下拉新增）、换地点、改日数 | 所有字段可改，日期预览实时跟随 |
| 3.4 | 类型为「移动」时 | 表单额外出现「持续天数」字段 |
| 3.5 | 速记里包含名单外的名字 | 参与者标签区出现提示「名单外：XX（未计入，可手动补）」，可通过下拉手动补选 |
| 3.6 | 点「记入世界」 | 小窗关闭；屏幕底部出现胶囊「已记录：XX · 日期」+「撤销」按钮；切片条数据随之更新（如在场变化） |
| 3.7 | 立即点击胶囊「撤销」 | 胶囊消失；去世界页确认该事件不存在；切片恢复原状 |
| 3.8 | 重复 3.6，但不点撤销，等待约 6 秒 | 胶囊自动消失；事件保留（去世界页事件列表确认存在，地图/时间轴回放已包含它） |
| 3.9 | 输入模糊/无意义的话（如「今天天气不错」）→ 解析 | 出现黄色提示（解析把握不高或未能解析），表单为空白可手填状态，不报错 |
| 3.10 | 点「← 重新速记」 | 回到一句话输入状态 |
| 3.11 | 速记框打开时再按 `Alt+N` 或 `Esc` | 小窗关闭，无残留 |
| 3.12 | 光标不在正文编辑区（如焦点在页面其他位置）时按 `Alt+N` | 不触发速记框 |
| 3.13 | 从浮卡「记一笔」进入 | 输入框已预填实体名，可直接续写事件 |
| 3.14 | 顶栏「?」快捷键速查表 | 列表中出现「Alt + N 世界速记」条目 |

## 4. 候选回流（写作 → 世界的变化收件箱）

前置：书 A，AI 模型可用。

| # | 操作步骤 | 预期结果 |
|---|----------|----------|
| 4.1 | 写一段含明确世界事实的正文（例：「林尘连夜启程，三日后抵达北岸要塞。王战死。」）→ 按 `Ctrl+Enter` 沉淀 | 沉淀正常完成；切片条出现「**N** 本章带来的世界变化」徽标块 |
| 4.2 | 展开收件箱 | 每条候选显示：事件类型、一句话摘要、发生日期，右侧 ✓ / ✗ 两个按钮 |
| 4.3 | 对「林尘抵达」候选点 ✓ | 候选消失；底部出现撤销胶囊；切片条「在场」中林尘位置更新为新地点 |
| 4.4 | 胶囊 6 秒内点「撤销」 | 事件被撤回：切片在场恢复、世界页事件列表无此事件、该候选重新回到待确认列表 |
| 4.5 | 对另一个候选点 ✗ | 候选消失且不再出现（见 4.8） |
| 4.6 | 执行「完稿审计」 | 审计正常完成；同样产生/更新候选徽标（整章抽取） |
| 4.7 | 打开世界页，查看侧栏「待确认」分区 | 显示全书（跨章）待确认候选；每条可 ✓ / ✗；✓ 后世界页事件列表与地图立即更新，出现成功提示 |
| 4.8 | 对同一段落重复沉淀两次 | 不产生重复候选（内容相同的候选只保留一条） |
| 4.9 | 沉淀一段纯对话/心理描写（无明确世界事实） | 不产生候选，或仅产生极少量合理项（记录误报率） |
| 4.10 | 断开模型服务后执行沉淀/完稿 | 写作、沉淀、审计主流程均不受影响；只是不出现候选徽标 |

## 5. 深链往返（写作页 ↔ 世界页）

| # | 操作步骤 | 预期结果 |
|---|----------|----------|
| 5.1 | 从浮卡「在世界页打开」跳转 | 世界页打开；时间轴游标停在本章时刻（时间轴高亮日期与切片条一致）；实体抽屉打开或地图定位到对象；页头出现「↩ 返回本章」 |
| 5.2 | 从切片条「打开世界页」/在场行跳转 | 同上（游标带本章时刻） |
| 5.3 | 点击世界页页头「返回本章」 | 回到写作页**原来那一章**，编辑内容无变化 |
| 5.4 | 从地点卡跳转 | 世界页定位该地点、游标停本章时刻 |
| 5.5 | 通过左侧导航正常进入世界页（非深链） | 页头**不显示**「返回本章」 |
| 5.6 | 深链进入世界页后录一条事件 → 「返回本章」 | 回到写作页后切片条已反映新事件（在场/红点，见 §6） |

## 6. 保鲜与双开同步

前置：两个窗口分别开同一本书的写作页与世界页。

| # | 操作步骤 | 预期结果 |
|---|----------|----------|
| 6.1 | 在世界页录一条事件（如角色移动）→ 切到写作页窗口（点击使其聚焦） | 数秒内切片条静默刷新；因内容确实变化，头部出现「世界有更新」红点提示 |
| 6.2 | 点击「世界有更新」 | 红点消失，切片保持新数据 |
| 6.3 | 在世界页做一次**不改变切片内容**的操作（如仅打开抽屉看一眼）→ 聚焦写作页 | 切片刷新但**不**出现红点 |
| 6.4 | 写作页持续打字（正文编辑状态）期间，另一窗口改世界数据 | 无需手动聚焦，数秒内切片自动更新（写作不打断、无弹窗） |
| 6.5 | 快速连续切换两个不同章节 | 切片内容始终与**当前**章节对应，不出现上一章数据残留闪烁后滞留 |
| 6.6 | 世界页修改本章叙事锚 → 聚焦写作页 | 切片条日期/徽标即时跟随新锚 |

## 8. 已知边界与降级预期（不是缺陷）

| 场景 | 预期行为 |
|------|----------|
| AI 模型未配置/故障 | 速记解析提示「未能自动解析」并可手填表单；沉淀/完稿不产生候选；写作、审计、切片展示均不受影响 |
| 未启用世界页的书 | 切片条只显示迁移引导；选中文本不出现浮卡 |
| 从旧设定迁移来的地点（无坐标） | 地点卡不显示控制区；相关深链不发生地图定位（属正常，坐标待在世界页补） |
| 纯阅读（长时间不打字） | 后台感知暂停，数据更新依赖窗口聚焦后数秒内刷新（秒级延迟属设计预期） |
| 候选抽取偶发漏抽/多抽 | 属模型概率行为；核心验收点是「✓/✗ 由作者裁决、不确认不入账」，个别误报记录在案即可 |
| 章节从未锚定且世界无事件 | 切片显示「世界起点」徽标，各数据块按缺席隐藏 |

## 9. 缺陷记录建议

- 每条缺陷附：书籍名 + 章节名、复现步骤、预期 vs 实际、截图/录屏；
- 优先级建议：
  - **P0**：主流程阻断（写作/沉淀/世界页报错、数据丢失、撤销失灵）；
  - **P1**：功能错误（✓ 不生效、切片数据与世界页不一致、深链落点错误、红点逻辑颠倒）；
  - **P2**：体验问题（浮层遮挡、文案、间距、延迟偏长）；
- 涉及 AI 输出的用例（§3 解析、§4 抽取）建议同一输入重复 2-3 次再定性，区分「模型偶发」与「功能缺陷」。
