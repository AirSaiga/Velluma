## 施工纪律（全部硬性）

- 设计稿附录的代码锚点**行号会漂移**，以模块名/函数名 grep 定位为准；
- 新 `.py` 文件加 AGPL 头（SPDX 两行，格式见 AGENTS.md 代码规范节）；
- 后端测试放被测模块旁（`test_*.py`）；前端测试**只放 `src/**/__tests__/`**（放别处会被静默跳过）；
- 改行为必须同步文档：AGENTS.md、对应 `docs/agent/*.md`、过程叙事进 `docs/incidents/*.md`；
  期次状态登记到 `docs/iteration-roadmap.md`；
- UI 文案用作者语言，工程黑话不上屏（口径见 AGENTS.md 术语节）；
- 现有测试基线（2026-09-18 实测）：**后端 1531 项 / 前端 370 项全绿**——你的改动不得让这个数变红；
- **不擅自 git commit**，用户确认后按指令提交；提交信息风格参照 `git log` 既有格式；
- 设计稿与代码现实冲突时，**停下来问用户**，不自行改设计。
