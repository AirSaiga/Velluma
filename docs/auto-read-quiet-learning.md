## 1. 战略定稿（六问 + 追加一问，2026-08-25 逐题拍板）

架构讨论（调研双智能体 + trace/DB/遥测三源实证）后用户逐题拍板：

1. **定位**：严肃长篇作者，做深不做宽；新手引导与代写档永久后置。
2. **大局层**：只做「一面镜子」——只读呈现全书形状，不给建议不改东西
   （DDE 式主动参谋不做）。
3. **打勾负担**：铁律「每条发现亲手确认」不动；减负靠**学着闭嘴**
   （被拒学习），不做默认转正。
4. **做深方向**：让它更懂这本书——投资世界/记忆/文风知识层的理解质量。
5. **数据托付**：纯本地不动摇 +「带得走」承诺（一键导出通用格式，缓行件）；
   云同步不做。
6. **验证方式**：只自己写——自用实测为唯一验证源。

**追加第七问（同日）**：喂养劳动在真实使用中零发生（《弦上灰》17 章零知识层、
沉淀/速记/文风页全零使用——冷启动死循环实证），破局 = **系统自己去读**：
观察触发权交给系统（切章/通读），候选池物理隔离与作者确认铁律不变——
喂养从「作者要做的事」变成「作者要批的事」。连带约束：自动观察必须带预算闸；
「学着闭嘴」须先于自动阅读上线（防洪闸）。

实测载体双轨：读《弦上灰》（17 章存量通读）、写《最终武装》（冷启动生长）。

## 2. 生成质量诊断（「驴头不对马嘴」三机制，trace 实证）

真实 trace（机甲书一章 4 次生成）坐实三机制，全部已修：

1. **配比倒挂**：stitch/continue 滚动窗口设计值仅 200 字，模型看到的「关于书」
   远多于「书本身」→ 执行大纲而非接作者的话。**修**：窗口 200→800 /
   burst·outline 500→1200（P1-3 短窗观测数据门达成解锁）；句界净截
   `sentence_clean_tail`（窗首丢弃半截句）；context-preview 同源。
2. **剂量错配**：点火把整章大纲地图喂给模型 → 700 字冲完袭击+跌落全序列。
   **修**：大纲就近化（意图块只给接下来一两拍，`outline_nearby` 共享模块，
   dock 挂件同源）+ 点火剂量闸（open 只给开头一两拍）。
3. **正向缺位**：新书期无样本无正向引导 → 模型回落默认腔。**修的方向** =
   自动阅读把知识层喂厚（第 3 节），正向示范靠作者真实文本积累。

附带实证缺陷修复：spine-suggest 800 token 被 MiMo 隐藏思考烧光返回空
（finish=length）→ 预算提 2400 + 空输出关思考兜底重试。

## 3. 工作包（提交 fb8e3c7 / 4d992c6 / 862132d）

### 3.1 学着闭嘴（被拒学习）

- 静音集合从行为**派生不落库**（候选裁决史 + hint_dismiss 埋点史），
  `books.assist_mutes` 只存宽恕时间戳（恢复=该时刻前记录一笔勾销）。
- 阈值纪律：裁决样本 ≥3 且零采纳才静音（一次肯定胜过三次否定）；
  提醒类 30 天窗口收起 ≥3 次静音（过期原谅）。
- 安全类（leak/contradiction）白名单外永不静音——穿帮预警不接受「别烦我」。
- 消费双通道：event_scout 生成侧（prompt 排除 + 落池过滤双闸）+ 心跳感知带过滤。
- 可见可恢复：`GET/POST /books/{id}/assist-mutes` + 副驾收件箱静音清单行。
- 幽灵蒸发理由条（失败分类学传感器）：Esc 蒸发 ≥30 字浮可选 chips
  （接错了/不像我/节奏不对/其他，8s 自灭），落 `ghost_discard_reason` 埋点。

### 3.2 系统自己去读（自动阅读 + 预算闸 + 全书通读）

- 预算闸 `read_budget.py`：章级内容哈希幂等（`chapters.auto_read_state`）+
  同章 300s 间隔 + 每书滚动 24h 上限 30 次（generation_runs 计数零新表）；
  跳过原因全人话；`force=True` 只豁免幂等闸（通读刷新丢 review 的补救），
  预算闸永不豁免。
- 端点：`POST /chapters/{id}/adaptive/auto-read`（事件候选）与
  `/read-entities`（实体候选只产草稿不落库）。切章自动发枪，后端闸门裁决。
- 全书通读向导（世界页待确认抽屉「通读本书」）：阶段 A 认人（逐章抽取→
  汇总去重→作者勾选才建）→ 阶段 B 记事；可中断、重跑幂等只补未读。

### 3.3 思考关闭语义修复

`get_default_reasoning_config` 的 `enabled=False` 从「不表态」改为显式关闭
（REASONING_DISABLED 同形）——MiMo 等厂商服务端默认思考开，「不发参数=开」。
OpenAI/本地端点经适配层分支零变化。此后「关思考」从调用点纪律变为默认正确。

## 4. 通读首秀实测四修（2026-08-25/26，28c8e73 / cdfb740 / 61bdd01 / b4e38b8）

首秀即实战验收，四处实测缺陷当场修复：

1. **冷启动自锁**：待确认图标栏原「有候选才渲染」→ 空箱书永远开不了抽屉
   （通读入口不可达）。改常驻 + 空态引导。
2. **层叠穿帮**：`.world-map-wrap` 补 isolation——空白舆图卡（z660）等覆盖层
   与页面模态（z110）在根上下文混排，曾压住通读向导挡住确认按钮。
3. **跨章重复**：event_scout pending 判重升全书级归一化子串；转正前账本判重闸
   （命中标 rejected + `auto_reject=duplicate` 留痕不建事件，quiet_learning
   不计假拒绝）；候选联表补 `chapter_number`，t=0 显示「第 N 章」不伪造默认日期。
4. **连点事故（本轮最重）**：确认建实体无防连点 + 无进度反馈，被连点 14 次建出
   14× 同名实体（1106 实体 + 387 地点副本）。双闸修复：前端忙碌闸 + 进度禁用；
   服务端实体/地点创建按（书+归一化名+类型）幂等（显式 id 的 undo/redo 重建
   路径豁免，同名不同类不误并）。存量数据已清库（留各组最旧者 + 事件/候选引用
   按 id 双形态重映射，备份 `data/backups/velluma-20260826-prededup.db`）。

**事故教训登记**（后续批次默认遵守）：UI 上所有「点击触发多次写」的按钮默认想
连点（忙碌闸 + 进度反馈是标配）；SQLite UUID 双形态（列存无横线 / JSON 存有
横线）是引用重映射必踩点。
