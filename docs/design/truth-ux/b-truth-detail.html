新增（只有两处）
  • 两个问句小标题——「问一 / 问二」替掉「两 面」「揭 示」两个分区题，字段各归其问。
  • 提醒回声——填「第几章揭 = 30」即出「写到第 28 章时，写作台会提醒你」。把既有 ≤2 章感知带规则显性化，零后端改动；字段从「记了就忘」变成「会看到它回来」。
收编与摘除
  • 因果图谱 · 一度 0 与 连锁分析 摘除——边永远建不起来，两者永远答「没有」，留着是谎话。
  • 钩子区（强度/状态/埋设手法） 摘除——与伏笔账本重复；存量 hook 条目此处改显示一行「这是旧『钩子』条目，建议迁入伏笔账本」。
  • 查片段 改名 贴段正文查泄密（能力保留：纯节点短语比对，不依赖边）。
  • 类型下拉 对已挂接条目降级为只读徽标——类型随对象推演，不再手改出矛盾。

三态行为不变：切「公开」时表卡消失（读者已知 = 里即事实，无需维护表象），释义行同步换成「已建立的事实，AI 必须遵守」； 切「半露」时释义行为「读者见过伪装版——两面都要维护」。「贴段正文查泄密」展开态维持现状：贴片框 + 命中列表逐条列出。
