世界页视觉方向对比

同一本书《最终武装》、同一份数据（1 地点 · 0 事件 · 6 实体）、同一气质（暖纸书卷气）， 三个方向只改「页面如何对待作者的目光」。点开各稿对比（建议各自新开标签页）。

方向 A

空白舆图与世界扉页

把「什么都没有」变成产品本身：空态即扉页，三步引导像书的开篇。

  • 中央题签：书名 + 一句引言 + 壹/贰/叁第一步
  • 顶栏收敛：一个主动作「记一笔历史」，其余安静
  • 侧栏改账本条目：左色条语义 + 衬线名字，去掉卡片盒与冗余徽章
  • 时间轴加厚为编年史带，空态文案承认「时间尚未流动」

改动量：中 —— 骨架不动，空态/侧栏/时间轴三个组件重写样式

方向 B

活舆图（沉浸画布）

地图即主页：实体直接活在图上，侧栏收成图标栏，浮出式抽屉。

  • 全幅羊皮纸 + 卷边暗角 + 水印题字
  • 实体 = 图上印章节点（衬线名签），地点 = 图钉
  • 侧栏 → 46px 图标栏 + 浮出抽屉，画布面积最大化
  • 手势提示产品化为「图例」卡（kbd 键帽，不再贴脸）

改动量：大 —— 布局结构重排（侧栏改栏+抽屉），世界页气质上限最高

方向 C

案头工作台

现状骨架一格不动，纯补「视觉完成度」这一道工序。

  • 纸感肌理 + 卷边暗影，消灭「没刷完墙」的米色平地
  • 侧栏卡片盒 → 账本条目（与 A 同款语义色条）
  • 空态收小变雅，占位框从开发语言换成作者语言
  • 时间轴加厚 + 鎏金游标 + 衬线大日期

改动量：小 —— 基本是 CSS 与文案层，风险最低，收益立竿见影

打开方向 C
建议：A + C 合并实施，B 留作远期方向。
A 与 C 不冲突——A 的价值在空态扉页与信息节奏，C 的价值在整体质感，两者合成「世界页该有的样子」， 且都不动布局骨架，一次可见。B 的沉浸舆图是更大的产品决策（实体节点直接上图涉及交互语义变化）， 建议在 A+C 上线、作者真的把世界填起来之后再评估——空舆图沉浸得再美，也不如先让作者愿意铺第一个点。

设计稿为纯静态 HTML（零依赖、零素材，纹理全部由 CSS/SVG 生成），仅作方向对比，不代表最终实现细节。
