设计注记 · v4 双视图 · 零数字工坊

  1. 双视图切换（拍板）：顶栏「工坊 / 实验室」分段器（实装可复用 SegmentedPill 组件，随顶栏常驻）；两视图各自布局、切换不卸载（草稿/开关驻留）。实验室从页底折叠舱升级为整页视图——内容多也不再是窄长滚动。
  2. 工坊零数字（拍板，最严档）：工坊视图不出现任何数字——开场白无条数、样本卡无字数、栏头无计数、收件箱大数字改为「候」字朱印标记；贴字占位文案也去掉字数建议。一切数字（含库存计数）只出现在实验室。
  3. 引导归实验室（拍板）：「样本攒够了——要不要提炼画像」建议横幅移入实验室顶部。工坊只管三件事：贴字、试写、守底线。
  4. 开场白=状态灯+一句话：薄荷呼吸点=「AI 正带着你的字」（状态语义，非数据）；「试写两句」滚动到靶场。零状态时（无样本）整页换成贴字邀请。
  5. 实验室内容自上而下：提炼建议 → 笔迹签名（墨迹图/金线/朱丝栏）→ 指纹九项指标格 → 逐章对账双图 → 画像编辑/字段锁 → 章级特例 → 负面清单全量+陈词库豁免。「← 回工坊」常驻右上。
  6. 试写对比双栏皮肤：「不带你的文风」素面灰字 vs 「照你的文风写」纸面朱丝栏衬线——两栏皮肤的差异本身就在演示装上字帖的价值；划选加拦截保留。
  7. 文案口径（本轮拍板）：工坊零术语零黑话、说完整话——「A/B 试写靶场」改「试写对比」、「基准输出/文风装载输出」改「不带你的文风/照你的文风写」、「收为样本」改「收进字帖」、贴字占位不再提指纹画像。实验室措辞精准克制——去掉 MATTR、语料、锚、台账、字段、全量面等行话；保留的专业词（句长起伏/碎句率/修辞密度等）都配一句完整解释。
  8. 工程承诺：功能零删减（样本 CRUD/收编/靶场划词/规矩开关/章级特例/扫描审稿/收件箱/提炼全保留）；token 全走五主题系统（原型内置 paper 浅/深切换）；实验室切换器与视图状态可深链（?view=lab 之类，实装时定）。
