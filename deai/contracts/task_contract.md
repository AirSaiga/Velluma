# 任务契约：中文去AI味改写小模型（≤100字片段）

- 版本：v0.1（阶段1定稿，2026-08-31）
- **已被 [docs/contract.md](../docs/contract.md)（v0.2，含六闸入库契约）取代**，本文件仅作历史保留；违禁词表机器可读源仍为本目录 forbidden_words.txt。
- 修改规则：任何条款变更必须升版本号，并在 docs/roadmap.md 留痕。
- 本文件是全项目的最高约束，脚本、数据、平台操作指引不得与之冲突。

## 1. 任务定义

- 输入：一段带"AI味"的中文片段，长度 ≤ 100 字。
- 输出：改写后的片段。只允许改**语言质感**（措辞、句式节奏、连接方式），输出长度 ≤ 原长 × 120%。
- 用途：阿里云百炼 SFT；效果不足时追加 DPO。
- 禁改清单：事实、数字、日期、专名、引文一律不动；不得新增观点，不得删减信息点。

## 2. 硬约束（C1~C6，不可违反）

| 编号 | 约束 | 校验方式 |
|---|---|---|
| C1 | 输入长度 ≤ 100 字（口径见 §3） | 自动 |
| C2 | 输出长度 ≤ floor(输入长度 × 1.2)。极短输入边界见 docs/open_questions.md Q2 | 自动 |
| C3 | 事实保真：数字/日期/专名/引文不变，无观点增删（可校验子规则见 §4） | 部分自动 + 人工抽查 |
| C4 | chosen/good 类输出禁止出现 contracts/forbidden_words.txt 中任何词；rejected 类输出不受此限 | 自动 |
| C5 | 数据格式：全部 JSONL；SFT 用 messages 结构；DPO 用 prompt/chosen/rejected。细节见 data_format.md | 自动 |
| C6 | 评测隔离：评测集与训练集不得共享事实素材（source_id），不得共享改写模板（template_id） | 自动（依赖 meta 字段） |

## 3. 计数口径（所有脚本统一采用）

- "字" = Unicode 字符数，等价于 Python `len(s)`；包含汉字、标点、空格、英文字母与数字；不含换行符。
- 所有校验脚本先对文本 `strip()` 再计数。

## 4. C3 的可校验子规则

自动部分（阶段2脚本实现）：

- R1 数字：输入中每个阿拉伯数字串（正则 `[0-9]+(?:\.[0-9]+)?%?`）必须在输出中出现，且出现次数不少于输入。中文数字（如"三个"）不自动校验，进入人工抽查。
- R2 引文：输入中成对引号（"" '' 「」 『』）内文本必须逐字保留；书名号《》内文本同样逐字保留。
- R3 疑似专名提示：英文单词/字母串、连续大写缩写、引号与书名号内内容，标记为"疑似专名"，仅提示，由人工确认。

人工部分（无法可靠自动判定）：

- R4 中文数字是否被改动（"三个"→"3个"算改写数字，默认不允许）。
- R5 观点增删与语义偏移。
- R6 语气是否越过"改质感"变成了"换说法导致歧义"。

## 5. 流程约束

- 每阶段完成 → 先跑 `scripts/check_stageN.py` 且退出码为 0 → 才向用户交付"下一步人工动作"清单。
- 阿里云百炼的平台规则未经人工确认，不得写入契约或作为脚本假设；不确定项一律登记 docs/open_questions.md。
- 每阶段只做当前阶段，不提前训练。
