# data/inbox/ — 真实素材收集箱（v2 扩量用）

## 你要收集什么

带"AI味"的真实中文片段，每段尽量 ≤100 字（超长也可以贴，我会按句子拆分处理）。来源不限，例如：

- 工作里的：周报总结、群通知、邮件正文、汇报话术
- 网上的：公众号推文段、营销文案、客服回复、百科/科普腔
- 生活里的：App 公告、物业/学校通知、活动文案
- （可选）你自己会高频处理的文体，比如小说叙事段——v1 没训过，你要用就得多喂

不要自己改写，原样贴进来——改写（good）由管线生成再过六闸。

## 格式约定（real_texts.txt）

- 一段一行，段与段之间不留空行；
- 行首可以用 `#类别|` 标注（可选，不标我来自动判断）：职场|公告|营销|客服|科普|叙事|其他
- 不知道来源分类没关系，先贴。

## 示例

```
#职场|本次迭代有效提升了工单处理效率，为后续流程优化夯实了基础。
#公告|敬请您知悉：本小区将于11月30日前完成燃气管道安全排查，感谢您的理解与配合。
```

## 我拿到之后的处理

真实片段 → 抽事实做卡（数字/专名/引文锁定）→ 教师生成 good → 六闸校验入库 → 与合成数据合并导出 → 重训。
